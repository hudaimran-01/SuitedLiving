# InsideOut

InsideOut is a HackPrinceton pitch prototype: apartment search for people with disabilities. The name is provisional.

A person chooses wheelchair, low vision, hard of hearing, or a mix. The sample listings are then ordered and reported for those needs. Findings stay split into observed features, possible barriers, and unknowns.

The four Princeton homes are fictional. The investigation notes are written for the demo.

## Run

```bash
npm install
npm test
npm run dev
```

Open the app and choose **Try the Princeton example**. That search is a 1-bedroom up to $2,400 for a wheelchair user. On the homes page, switch the chips to **Low vision** or **Hard of hearing** to see the order change.
