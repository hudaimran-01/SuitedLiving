# SuitedLiving

HackPrinceton project for accessible home search.
https://github.com/hudaimran-01/SuitedLiving.git

## Layout

- `frontend/` holds the SuitedLiving web app. Run instructions are in `frontend/README.md`.
- `backend/` holds the API and scripts.
- `.env.example` lists environment variable names. Copy it to `.env` locally. Do not commit secrets.

Keep frontend work inside `frontend/` and backend work inside `backend/` so the two sides are not editing the same files.
