# SuitedLiving

**Find a home that fits your life.**

SuitedLiving is a personalized housing discovery platform that helps people with disabilities explore homes based on their individual accessibility needs. By combining property listings with interior and exterior spatial data, it helps renters understand potential accessibility barriers before visiting a property.

### 🔗 Live Demo

**[Try SuitedLiving](https://suited-living.vercel.app/#/)**

### Features

- **Personalized housing search:** Explore properties based on individual accessibility requirements.
- **Interior accessibility insights:** Investigate room layouts and potential barriers using available floor plans and interior scans.
- **Neighborhood exploration:** Consider building surroundings and nearby amenities.
- **Interactive floor plans:** Visualize accessibility considerations room by room.
- **Evidence-based findings:** Distinguish potential barriers from information that still needs verification.

### Tech Stack

| Technology | Purpose |
|---|---|
| React + Vite | Frontend |
| Flask + Python | Backend |
| CoStar | Property listings and building data |
| Matterport | Interior 3D scans |
| Vexcel | Exterior aerial imagery |
| Vercel | Deployment |
